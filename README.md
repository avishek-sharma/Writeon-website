# Writeon Research and Analytics (P.) Ltd. — Official Website

A modern, responsive, multi-page web platform for **Writeon Research and Analytics (P.) Ltd.**, built with semantic HTML5, modern CSS3, and vanilla JavaScript.

---

## 🏛️ About the Organization

**Writeon Research and Analytics (P.) Ltd.** is a research consulting and capacity-building institution based in Kathmandu, Nepal. The firm bridges cutting-edge econometric modeling, institutional research consulting, and advanced data intelligence to empower decision impact for academic institutions, development agencies, and corporate enterprises.

* **Tagline:** Insight. Analysis. Impact.
* **Location:** Budhanilkantha / Kathmandu, Nepal

## ⚡ Tech Stack & Architecture

* **Frontend:** Semantic HTML5, Modern CSS3, Vanilla JavaScript (ES6+)
* **Dependencies:** None (Zero external libraries or build frameworks; lightweight and fast loading)
* **Design System:** Custom CSS variables for typography, spacing scales, and organic shapes
* **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) via Google Fonts
* **Responsiveness:** Fluid breakpoints covering mobile (≤ 480px), tablet (≤ 768px), laptop (≤ 1024px), and desktop viewports
* **Brand Palette:**
  * **Deep Forest Teal:** `#113E3D` (Primary)
  * **Accent Gold / Ochre:** `#C59B27` / `#C58F49` (Accent)
  * **Ivory Cream:** `#FDFBF7` / `#FAFAF8` (Surface / Background)
  * **Emerald Mint:** `#10B981` (Accents)

## 💻 Getting Started (Local Development)

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/writeon-research.git
cd writeon-research
```

### 2. View in Browser
Open `index.html` in any modern web browser:
* Double-click `index.html`, or
* Run a local development server (e.g., using VS Code **Live Server** extension, or `python -m http.server 8000`).

---

## 🚀 Key Features

* **Multi-Page Architecture:** Independent semantic pages (`index.html`, `about.html`, `services.html`, `contact.html`) with synchronized active navigation states.
* **Direct Connect Inquiry Hub:** Built-in modal allowing users to connect instantly via preferred webmail providers (Gmail, Outlook, Yahoo) or system default email clients.
* **Custom Responsive Navigation:** Mobile drawer menu with animated hamburger toggle and smooth viewport transitions.
* **CSS Grid & Micro-Animations:** Fluid layout compositions with performant CSS transitions.
