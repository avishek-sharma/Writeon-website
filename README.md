# Writeon Research and Analytics (P.) Ltd. - Website

A modern, responsive website for **Writeon Research and Analytics (P.) Ltd.** built using vanilla **HTML5, Custom CSS, and JavaScript**, faithfully matching the official UI design.

---

## 📁 Project Structure

```
writeon-research/
│
├── index.html        # Main HTML file containing all 4 sections & SVG graphics
├── style.css         # Custom CSS with design tokens, responsive grids & organic shapes
├── script.js         # Mobile menu animation & active link scroll-spy
└── README.md         # Documentation & setup guide
```

---

## 🚀 How to Run the Website Locally

You don't need to install Node.js, npm, or any build tool!

1. Open your File Explorer.
2. Navigate to:  
   `C:\Users\L E N O V O\Desktop\writeon-research\`
3. Double-click **`index.html`** to open it in your browser (Google Chrome, Microsoft Edge, Firefox, etc.).

## 🎨 Features & Design Match

- **Design Aesthetic:** Exact match to the UI mockup with Deep Forest Teal (`#113E3D`), Golden Ochre (`#C58F49`), Sage Green, and Warm Peach accents.
- **Section 1 (Home):** Hero banner with tagline, CTAs, 4 feature badges (*Expert Guidance, Data-Driven Insights, Capacity Building, Quality & Integrity*), and workspace laptop illustration.
- **Section 2 (About Us):** Overview, Mission, Vision, Values, and floating dark teal quote card.
- **Section 3 (Services):** 4-card service grid and bottom wavy customized solution banner.
- **Section 4 (Contact Us):** Office location in Putalisadak, Kathmandu, Nepal, business hours, and our **Direct Connect Hub** with instant clickable channels for:
  - 🟢 **WhatsApp** (opens WhatsApp chat with prefilled message)
  - 🔵 **Facebook Messenger** (opens Messenger inbox)
  - 🔴 **Gmail / Email** (opens email composer with prefilled subject)
  - 📞 **Direct Call** (opens dialer on mobile)
- **Responsive Layout:** Optimized for mobile phones, tablets, and desktop monitors.

## 🌐 How to Deploy (Publish to the Internet for FREE)

Since this project has zero backend requirements, you can deploy it in less than 2 minutes using **Netlify Drop**:

1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `writeon-research` folder into the upload box on Netlify.
3. Your website is immediately published with a live URL (e.g., `https://writeon-research.netlify.app`) and a free SSL certificate!
4. *(Optional)* Connect your free Nepal `.com.np` domain or any custom domain from the Netlify dashboard.
